Uppercase bold button; use `accent` (gold) for the single main CTA per section, `primary` (blue) elsewhere, `whatsapp` for contact.
```jsx
<Button variant="accent" size="lg">Falar no WhatsApp</Button>
<Button variant="outline">Ver produtos</Button>
```
Variants: primary, accent, outline, ghost, inverse (for dark blue panels), whatsapp. Sizes sm/md/lg (36/44/54px). Props icon / iconRight take a Lucide `<i data-lucide>` or SVG.
